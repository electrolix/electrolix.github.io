## About Electrolix

Electrolix is built around a simple purpose: making electrical product information easier to understand and use.

The website publishes educational articles and resources about electrical products, their specifications, common applications, and factors to consider when selecting them. Topics range from household wiring and wire sizes to industrial cables, electrical protection, lighting, and product comparisons.

Electrolix supports both business-to-business (B2B) and business-to-consumer (B2C) audiences. Its content is intended to help readers conduct product research and make more informed decisions before evaluating suitable products or purchasing options.

## Run Locally

You can clone the repository and open the website locally to review its pages.

### 1. Clone the repository

```bash
git clone https://github.com/electrolix/electrolix.github.io.git
```

### 2. Enter the project directory


### 3. Open the website

Open `index.html` in a web browser or use a local development server to test the site.

## Content Quality and Electrical Safety

Electrolix aims to provide clear, useful, and technically responsible electrical information.

Readers should:

- Verify product ratings and specifications against official manufacturer documentation.
- Confirm compatibility with the intended application.
- Follow applicable electrical codes, standards, and installation requirements.
- Consult qualified professionals for electrical installation, testing, and repair where required.

Educational articles are not a substitute for professional engineering advice, manufacturer instructions, or applicable safety requirements.

Product features, specifications, availability, and prices may vary by model, manufacturer, supplier, and location.
